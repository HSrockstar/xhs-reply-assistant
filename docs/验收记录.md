## CUDA 验证

设备 NVIDIA GeForce RTX 4060 Laptop GPU，约 8 GB 显存；驱动 581.08。PyTorch `2.8.0+cu128` / CUDA `12.8` / Sentence Transformers `5.1.1`。

固定 BGE revision 为 `7999e1d3359715c523056ef9478215996d62a620`。实际模型参数和资料/查询编码输出位于 `cuda:0`；向量归一化、矩阵相似度及 top-k 也在 GPU 执行。仅索引缓存序列化到 CPU/磁盘。

独立六文档、两查询验证中，FP16 与 FP32 的前3候选完全一致。该小样本不能证明所有问题精度一致。此轮冷加载约23.38秒、索引727 ms、查询233 ms、峰值已分配显存105.29 MB；不作为大规模性能承诺。

正式服务资料库为空，因此当前运行状态显示 CUDA 可用、索引尚未建立；真实推理通过的证据来自隔离合成资料验证。
